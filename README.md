My version of Pyinstein a code-based Bibite creator and Editor.<br>
Write python code to modify a bibites brain.

This tool is free to use and you are allowed to modify any file to your liking.

### How to use the tool?
Before you start make sure you have a standard installation of python 3.x and make sure the libraries json, os and pathlib are installed (usually come preinstalled with python)

1. Download load_bb.py and save_bb.py and place them in the same folder
2. Run load_bb.py in a terminal and follow printed instructions
3. Open the generated edit_brain.py in any text/code editor you wish to use. There you will see the brain and genes of the loaded bibite. 
4. Now you edit the brain by editing edit_brain.py. I don't feel like explaining here so read the comments in the edit_brain.py file for an explenation of how to do so.
5. When you are finished run the edit_brain.py file you just edited in a terminal and follow what is printed.
6. Now the modifications are saved to the choosen bibite, go ahead and use the bibite.

You have now edited a bibite brain by writing/modifying a couple of python lines
